# AeroStudio v0.1.0-beta.1 — Windows Public Beta

AeroStudio brings together three aviation-focused desktop creative tools:

- **AeroRoom Studio** — RAW photo development and aviation editing presets.
- **AeroFilm Studio** — timeline video editing, aircraft identification captions and flight-shot logs.
- **AeroPhoto Studio** — layered image editing and aircraft information graphics.

## Downloads

- **AeroStudio-Launcher-Windows.zip** — recommended, lets you install and launch any of the three apps.
- **AeroRoom-Launcher-Windows.zip** / **AeroFilm-Launcher-Windows.zip** / **AeroPhoto-Launcher-Windows.zip** — single-app installers.
- **AeroRoom-Windows.zip** / **AeroFilm-Windows.zip** / **AeroPhoto-Windows.zip** — standalone prebuilt Windows applications.

Download a ZIP, extract it and run the `.cmd` launcher or application `.exe` as appropriate. No Rust toolchain is required to run a prebuilt app. See `SHA256SUMS.txt` for checksums.

## Beta notes

The editors are modified versions of existing open-source editing engines. Aviation features and export quality are under development. Keep copies of important photos and projects and report issues using GitHub Issues.
