IMPORTANT · FIRST-RUN SETUP

AI denoising requires a
one-time model download.

Once a working version is released, The AeroEnhance Windows ZIP does not include pretrained model weights. After installing the app, run the included batch file to download SCUNet before enabling neural denoising.

01

Open the AeroEnhance folder

If installed through the unified launcher, open this location in Windows File Explorer:

%LOCALAPPDATA%\AeroStudio\Apps\AeroEnhance

If you extracted the standalone ZIP, open its AeroEnhance-Studio folder instead.

02

Run the included BAT file

Double-click download-scunet-model.bat. It fetches and verifies the two files needed for the SCUNet ONNX denoiser, into the local models folder. Keep both files together.

▣ download-scunet-model.bat
03

Enable the model in AeroEnhance

Restart the app or choose Detect installed in the AI panel. Enable neural inference; select your preferred compute device and test a photograph.

✳

The model is a third-party SCUNet export downloaded from Hugging Face; it is not trained by AeroStudios. NVIDIA CUDA may additionally require compatible GPU drivers and runtime libraries. Read the installation guide ↗
