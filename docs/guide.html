01 / INSTALL

Start with the launcher.

Get the AeroStudio Launcher from the official GitHub Release. Extract the ZIP to a normal Windows folder and start AeroStudio.cmd.

Prefer a standalone app?

Individual downloads are also available on the downloads page. AeroEnhance’s standalone CUDA ZIP should be extracted with its included DLLs and scripts kept beside the executable.

02 / FIRST LAUNCH

Choose your tool.

Use the launcher to install the app you want, then open it. AeroRoom is for RAW photos, AeroEnhance for image denoising, AeroPhoto for graphics and AeroFilm for video editing.

03 / AI MODEL SETUP

One extra step for AeroEnhance.

The AI denoising model does not ship inside the application ZIP. It must be downloaded once after installation before neural denoising becomes available.

  1. Open %LOCALAPPDATA%\AeroStudio\Apps\AeroEnhance for a launcher installation, or the extracted AeroEnhance-Studio directory for a standalone install.
  2. Double-click download-scunet-model.bat. Let it download and SHA-256 verify both the .onnx and .onnx.data files.
  3. Restart AeroEnhance or click Detect installed. Enable the neural model in the AI settings.
CUDA users

The CUDA build may require a compatible NVIDIA driver and CUDA/cuDNN runtime libraries. Neural model downloads and GPU runtime setup are separate tasks. If CUDA fails, check the app’s diagnostic output rather than downloading DLLs from untrusted sites.

04 / TROUBLESHOOTING

Need a hand?

AeroEnhance says its model is missing. +

Run download-scunet-model.bat in the installed AeroEnhance folder, wait for verification to finish, and restart the app or click Detect installed.

My AeroEnhance download fails verification. +

The unified launcher verifies the release ZIP against an embedded SHA-256 checksum. Avoid bypassing it. Check that the GitHub Release asset matches the version listed by the launcher; you can report a mismatch through GitHub Issues.

Can I use the apps individually? +

Yes. The downloads page offers standalone Windows packages and individual launchers for the original three apps, plus available AeroEnhance packages.

Does AeroEnhance upload my photographs or train on them automatically? +

No. Community training is an invitation-only pilot, not a live worldwide service. Contribution is off by default; you must submit approved examples explicitly and grant separate training permission. Future AI model downloads are controlled independently from contributing photos.

Are the apps finished? +

No — this is a public beta. Features, file support and performance are under active development, so keep backups of important projects and originals.
