GETTING STARTED

How to use the suite

Clear guidance helps first-time visitors understand what to download and how the apps fit together.

01

Choose your install

Download the main AeroStudio Launcher for the full suite, or use the standalone app or individual launcher downloads if you only need one app.

02

Edit your files

Use AeroRoom for RAW development, AeroEnhance for AI image restoration, AeroFilm for video and AeroPhoto for graphics.

03

Export and create

Export your finished media and combine apps as needed — for example, AeroPhoto graphics can go into AeroFilm projects.

Public beta notice: AeroStudio is already usable, but it is still evolving. Expect active improvements and occasional bugs as the suite develops.
